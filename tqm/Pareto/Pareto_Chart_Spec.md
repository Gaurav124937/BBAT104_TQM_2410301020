# Pareto Chart Specification

## Chart Type

A Pareto chart should contain:

- Bars ordered from highest to lowest defect frequency.
- A cumulative-percentage line.
- A horizontal 80% reference line.
- Category labels on the X-axis.
- Frequency on the primary Y-axis.
- Cumulative percentage on the secondary Y-axis.

## Data File

Use `Pareto_Data.csv`.

## Key Finding

The cumulative percentage reaches approximately **76%** after the first four
categories. The 80% threshold is therefore reached just after the
Visibility category.
