# PDCA Cycle — DO

## Implementation Activities

The planned improvements are carried out through controlled development and
testing activities.

### Validation

- Test quantity and required fields.
- Test invalid and boundary values.
- Confirm clear feedback for rejected inputs.

### Transaction Accuracy

- Test available-book issue flow.
- Test duplicate active issue prevention.
- Test valid return flow.
- Verify availability updates after return.

### Search / Retrieval

- Test book search.
- Test member search.
- Test Records search by title, member and transaction IDs.
- Test status filtering.

### Visibility

- Verify Records status classification.
- Verify Dashboard values against stored transactions.
- Verify Calendar issue, due and return events.

## Execution Rule

Every corrective action should be followed by a verification test and a defect
log update.
