# PDCA Cycle — PLAN

## Objective

Use the Pareto and Fishbone findings to reduce the highest-priority usability
and transaction-quality defects in the Library Management System.

## Problem Statement

The Pareto analysis identified Validation, Transaction Accuracy,
Search/Retrieval and Visibility as the largest defect categories.

## Improvement Objective

Prioritize corrective actions that improve:

- Input validation
- Issue/return transaction accuracy
- Search and record retrieval
- Dashboard/calendar/records visibility

## Plan

| Action | Responsible Role | Measure | Target |
|---|---|---|---|
| Strengthen input validation | Developer | Invalid inputs accepted | Zero critical invalid cases |
| Verify issue/return workflows | Developer | Transaction defects | Reduce transaction defects |
| Test search/filter behavior | Developer | Search misses | Zero known search misses |
| Verify visibility views | Developer | Missing/mismatched status | Zero known visibility mismatches |

## Baseline

Use the existing Defect Control checksheet and Pareto frequencies as the
baseline for later comparison.

## Expected Outcome

A measurable reduction in the highest-frequency defect categories and improved
user confidence in the library workflow.
